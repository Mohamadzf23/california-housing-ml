# California Housing ML

A machine learning project for predicting California house prices using Python and Scikit-learn.

## Project Overview

In this project, I work with the California Housing dataset and build regression models to predict `median_house_value`.

The project follows a complete machine learning workflow, from data exploration and preprocessing to model training and evaluation.

## Dataset

The dataset contains information about different districts in California.

Main features include:

- `longitude`
- `latitude`
- `housing_median_age`
- `total_rooms`
- `total_bedrooms`
- `population`
- `households`
- `median_income`
- `ocean_proximity`

### Target

`median_house_value`

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Workflow

The project covers:

- Exploratory Data Analysis (EDA)
- Data Cleaning
- Handling Missing Values
- Feature Engineering
- Categorical Encoding
- Feature Scaling
- Train/Test Split
- Model Training
- Model Evaluation
- Cross-Validation

## Preprocessing

The following Scikit-learn tools are used:

- `train_test_split`
- `KNNImputer`
- `IterativeImputer`
- `StandardScaler`
- `MinMaxScaler`

## Regression Models

The following models are explored and compared:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- HistGradientBoosting Regressor

## Model Evaluation

The models are evaluated using regression metrics such as:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
- Cross-Validation

## Project Goal

The goal of this project is to practice and understand the complete machine learning workflow for a real-world regression problem, including data preprocessing, feature engineering, model training, and evaluation.
